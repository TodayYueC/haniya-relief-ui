# Multi-language UI

Implementation: `compose/i18n/I18n.kt`, `compose/component/I18nText.kt`, `compose/i18n/i18n_extract.py`.

## Approach
Write the UI in the source language (Chinese) directly in code. Translation happens at render time:
1. A drop-in `Text` (same signature as Material3, plus `translate = true`) calls `I18n.tr(text, LocalLanguage.current)`. Swap `import androidx.compose.material3.Text` for the wrapper; nothing else changes. Pass `translate = false` for user content and AI output.
2. Lookup order: exact → template (`{0}` placeholders compiled to regex, longest literal first, captured CJK recursively translated) → strip symbol prefixes/suffixes (`✓ 今天`) → split on separators (` · `, `，`, `。`, `：`, `、`, `\n`…) and map Chinese punctuation to the target language's.
3. Untranslated text falls back to the source string — never crashes, never blank.
4. Catalogs: `assets/i18n/source.txt` + one file per language, **line-aligned**. A unit test asserts equal line counts and identical placeholder sets.
5. Non-Compose code (notifications, formatters) calls `I18n.tr(...)` directly; dates/weekdays use `DateFormat.getBestDateTimePattern(locale, "MMMMEEEEd")`.
6. Language choice: "follow system" default; mirrored to SharedPreferences for cold paths; on Android 13+ also set `LocaleManager.applicationLocales` so system widgets switch.
7. AI features: keep prompts in the source language but append "always reply in <language>".

## Gotchas
- Android's ICU regex needs `\\}` escaped — `Regex("\\{(\\d+)\\}")`, not `"\\{(\\d+)}"` (that one crashes at startup on device but passes on the JVM).
- Same source word, different meaning in context → give one use site a distinct key (e.g. a chart legend "each entry" vs. a card title "daily log").
- Long compounds (German) → cap row values, prefer shorter translations, icon-only nav.
- Traditional Chinese: generate with OpenCC `s2twp` for consistency.

## Adding strings
`python compose/i18n/i18n_extract.py <project-root> out/` → diff `out/source.txt` against the shipped source → append new lines (same order) to every language file → run the alignment test.
